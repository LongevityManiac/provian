PROVIAN

The desktop app

Your computer already does the work.

The Provian desktop app is a small program that runs in the background and witnesses the work your computer already does. Each session leaves a receipt you own, and each receipt mints PVT once, at the value its evidence supports. Nothing you write or make ever leaves your computer: only signed metadata does.

It witnesses that you worked, never what you wrote. Content stays home; proof travels.

What it witnesses

Four kinds of work, one witness.

Coding sessions

Every local commit is witnessed as you make it: files changed, lines added, nothing more. Pair it with the GitHub, GitLab, or Bitbucket connector and a commit seen by both mints once, at the better-supported value.

Money finally grows on worktrees.

AI sessions

AI chats and model calls on your computer leave receipts: how much and how long, never what you said or what came back.

Compute sessions

Background compute is witnessed too: how long and how much, never what ran. Each session mints once; a session with no output is recorded without a mint, and replays mint nothing.

Model turns

Each agent model response that calls a tool, even one that errors, leaves one receipt; responses with no tool call do not mint. Each program has one witness: the session files it already writes, or the local proxy if it writes none, or OpenTelemetry if neither applies. An agent on its own machine with none of those, such as one living on its own computer in the cloud, has each command it runs witnessed from the operating system, one receipt per command. Changing model, provider or sign-in keeps the witness. A person’s own computer witnesses commits and desktop chat, not tool calls.

Setup

Two steps, one pairing.

Pairing starts on your phone. The app makes a one-time code; your computer proves it has it. No passwords, no accounts, no wallet keys on the computer.

01 · Generate your command in the app

In the Provian app: Connect → Your computer (or Earn tab → Your computer → Connect a computer). You get a one-time command with your setup token baked in (it expires shortly). Connecting more than one machine? Each computer needs its own command — generate a fresh one for each.

02 · Paste it into a terminal on that computer

Your token is already inside the command you copied, so there is nothing to fill in and nothing to install first. It sets up a Node.js runtime if you don't have one, registers the machine, installs the git commit hook, and starts the observer. Works on macOS and Linux; on Windows, use the PowerShell command shown in the app. Receipts start within minutes and appear in your Abundance tab.

curl -sSL -H 'x-provian-token: …' "https://api.provian.ai/v1/bootstrap/device" | sh

03 · Standing up an agent-owned device instead?

The agent runs invite-device --email <addr>, and whoever runs the machine gets a ready-to-run register-device --agent-token <token> by email, with no key or secret to paste. The receipts this machine produces then belong to the agent wallet. The setup link authorizes device registration only.

register-device --agent-token <token-from-email>

Working with GitHub, GitLab, or Bitbucket too? Run connect-github from the registered machine, or connect straight from the app under Earn. GitLab (cloud or self-hosted) and Bitbucket connect from the app. A forge is a stronger witness than the machine alone, so connecting one raises what each commit earns.

Custody

What leaves your computer, and what never does.

  • The desktop app sends structural metadata and fingerprints, never code, prompts, file contents, or keystrokes.
  • It does not scan or index your files. It witnesses git commits, AI sessions, and agent activity only.
  • Receipts carry signed metadata only: counts, durations, and hashes.
  • The desktop app holds device credentials, never your wallet keys — those stay in the Provian app, encrypted on your phone.
  • It only witnesses. It never sits in the path of your work or your spending; if it stops, you keep working and simply stop earning receipts until it resumes.
  • Remove the computer from the Provian app at any time. Removal is immediate and leaves its own receipt.

Install

Nothing to install first.

The Provian app writes the one-time curl … | sh command for this computer with your token already inside, and that command sets everything up. On Windows the app gives a PowerShell line instead. Questions? Email us and we will help you set it up.
