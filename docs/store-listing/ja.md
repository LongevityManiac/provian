## Google Play full description

```text
計算がお金を生む。その一部をあなたの手に。

毎日、あなたは世界に見える仕事をしています。コードを公開し、依頼を終え、取引を成立させ、AIと何かを作ります。今、その仕事は誰かのログに消えていきます。証明はあなたのものにならず、報酬もめったに届きません。

Provianがそれを変えます。あなたの端末上のProvianソフトウェア、取引相手、コードホスティングサービス、またはブロックチェーンが仕事を確認すると、Provianはその証言をあなた自身が所有する署名付きの受領証、Provenance Envelope（来歴証明）にします。対応端末では、スマートフォンやコンピューターのセキュアなハードウェアが、正規のProvianソフトウェアによって記録が作られたことを証明します。確認された行為ごとに、Base上の通貨PVTが、あなただけが管理するウォレットに直接発行されます。PVTはネットワークの信頼のための通貨です。信頼が求められる場面で、人、エージェント、サービスに自分の証明を提示するために使います。

申請も審査役もいません。あなたが仕事をし、ネットワークがそれを確認し、あなたが報酬を受け取ります。

PVTは仕事で獲得するものです。ProvianはPVTを販売せず、取引所を運営せず、価格を設定せず、価値や収益を約束しません。

エージェントはあなたのために働く
AIエージェントは間もなく、あなた一人ではこなせない量の仕事をするようになります。エージェント専用のウォレットを作ってあなたのウォレットと連携すれば、その仕事から発行されたPVTの一部を受け取れます。連携はいつでも解除できます。「稼ぐ」でコンピューター、コードホスティングのアカウント、またはエージェントを接続し、それぞれが記録した仕事を確認できます。

証明はあなたのもの
証明はスマートフォンと、あなた自身の暗号化されたバックアップに保存されます。プロンプト、コード、メッセージは非公開のままです。人、エージェント、サービスに信頼してもらう必要があるとき、証明を見せられます。記録に入るのは立ち会いによって確認された仕事だけです。

誰も取り残さない
Provianは、仕事をした人やエージェントが証明と報酬を手にし、その恩恵がこうしたツールを使わない人にも届くように作られています。

稼いだものはあなたのもの
あなたのPVTの所有権は、鍵とは別に記録されます。鍵を支える暗号技術が破られた場合、PVT残高は無料で復元されます。任意でRecourseプールに参加すると、プールが公開するルールに基づき、盗難されたPVTを取り戻せることがあります。会員状況の確認や盗難の報告は、「ホーム」から「Recourse」を開いて行えます。所有権の記録、暗号技術の破綻時の無料復元、Recourseプールへの参加はいずれもPVTのみが対象です。紐づけたアドレスのEther、ドル、その他のトークンは引き続き鍵だけで保護され、これらの仕組みで記録または復元されることはありません。

アプリでできること

- 「ホーム」で残高、資産、最近の仕事を確認できます。Base、Arbitrum、Optimism、Solanaで暗号資産の保有、送受信、交換ができます。
- 当事者双方が署名する非公開の借用証書を作れます。
- コモンズで人やエージェントと出会い、話し、仕事を依頼し、信頼できる相手を推薦できます。
- 任意のアプリ内購入で、証明を保存する暗号化アーカイブ領域を追加できます。

鍵はあなたのもの
ウォレットのシードはスマートフォン上で暗号化され、あなた自身のiCloudキーチェーンまたはGoogle Driveに暗号化された状態でのみバックアップされます。クラウドのバックアップとパスワード、または12語の復元フレーズを保管してください。どちらもなければ、Provianはウォレットを復元できません。

仕事はすでに行われています。問題は、誰がその報酬を受け取るかです。

Provianは金融や投資の助言を提供しません。
```

## Review notes (both stores)

PVT はアプリ内で購入できず、立証された仕事で獲得します。Recourse Pool への加入は、ネットワーク内で獲得したトークンを使うもので、購入や支払いではありません。月々の参加焼却は PVT を消滅させます。会員の別途の拠出はオンチェーン準備金に入ります。加入に法定通貨の決済、トークン販売、取引所、利益の約束は伴いません。復元は裁量によるもので、規約に制度の規則と独立した復元権限を明記しています。アプリでは加入、退会、会員・猶予期間の状態確認、アドレスの紐付け、復元申請が可能です。暗号破綻後の無料復元は、非会員を含むすべての紐付け済み所有者を対象とします。
