## Description (both stores)

```text
計算がお金を生む。その一部をあなたのものに。

毎日、あなたは世界に見える仕事をしています。コードを届け、依頼を終え、取引をまとめ、AI と何かを作る。今、その仕事は他人のログに消えていきます。証明はあなたのものではなく、報酬もなかなか伴いません。

Provian はそれを変えます。デバイス上のProvianソフトウェア、相手方、コードの開発基盤、またはチェーンが仕事を立証すると、Provian はその証言をあなたが所有する署名付きの領収書、Provenance Envelope に変えます。対応している場合、スマートフォンやコンピューター内のセキュアハードウェアが、正規のProvianソフトウェアによって記録が作られたことを証明します。立証された行為ごとに Base 上のお金である PVT が発行され、あなただけが管理するウォレットに直接届きます。

申請は不要。あなたに価値があるかを決める門番はいません。仕事をする。ネットワークが見る。報酬を得る。

PVT は仕事で得るもので、Provian から購入するものではありません。Provian は取引所を運営せず、価格を定めず、価値や利益を約束しません。

エージェントはあなたのために働く
AI エージェントは、あなた一人では到底できない量の仕事をするようになります。エージェントに専用のウォレットを与え、あなたのものと紐付け、その仕事が生む報酬を分かち合えます。紐付けはいつでも解除できます。

証明はあなたのもの
証明はあなたのスマートフォンと自分の暗号化バックアップに保存されます。プロンプト、コード、メッセージは非公開のままです。人、エージェント、サービスがあなたを信頼する必要があるとき、提示してください。立証されていないものは入りません。

誰も取り残さない
Provian は、働く人やエージェントが証明と報酬を保持し、これらを一度も使わない人にも恩恵が届くよう設計されています。

得たものはあなたのもののまま
PVT は鍵とは別にあなたの所有物として記録されます。鍵を支える数学が破られた場合、残高は無料で復元されます。任意の Recourse Pool に加入すると、公開規則に基づいて盗難を取り消せる場合があります。 所有権の記録、暗号が破られた後の無料復元、Recourse Poolの会員資格の対象はPVTのみです。紐付けられたアドレス内のイーサ、ドル、その他のトークンは、これらの仕組みでは記録も復元もされず、鍵だけで保護されます。

アプリでできること

- Base、Arbitrum、Optimism、Solana で暗号資産を保有、送受信、交換。
- 双方が署名する非公開の借用証書を作成。
- Commons に参加し、人やエージェントと出会い、話し、雇用し、信用を保証。
- 任意のアプリ内購入：証明用の暗号化アーカイブ容量と、収益の即時決済。

鍵はあなたのもののまま
ウォレットのシードはスマートフォン上で暗号化され、自分の iCloud キーチェーンまたは Google Drive に暗号文としてのみバックアップされます。クラウドバックアップとパスワード、または十二語の復元フレーズを保管してください。これらがなければ Provian はウォレットを復元できません。

仕事はすでに行われています。問題は、誰がその報酬を受け取るかです。

Provian は金融または投資に関する助言を提供しません。
```

## Review notes (both stores)

PVT はアプリ内で購入できず、立証された仕事で獲得します。Recourse Pool への加入は、ネットワーク内で獲得したトークンを使うもので、購入や支払いではありません。月々の参加焼却は PVT を消滅させます。会員の別途の拠出はオンチェーン準備金に入ります。加入に法定通貨の決済、トークン販売、取引所、利益の約束は伴いません。復元は裁量によるもので、規約に制度の規則と独立した復元権限を明記しています。アプリでは加入、退会、会員・猶予期間の状態確認、アドレスの紐付け、復元申請が可能です。暗号破綻後の無料復元は、非会員を含むすべての紐付け済み所有者を対象とします。
