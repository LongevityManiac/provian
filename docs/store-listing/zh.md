## Description (both stores)

```text
计算创造货币。让其中一部分归你所有。

每天你都在做世界看得见的工作。你发布代码、完成任务、谈妥交易，或与 AI 一起创造。如今，这些工作消失在别人的日志里。证明不归你，报酬也很少随之而来。

Provian 改变这一点。当你设备上的 Provian 软件、交易对方、代码托管平台或区块链见证你的工作时，Provian 会把这份见证变成归你所有的签名凭证：来源证明信封（Provenance Envelope）。在受支持的设备上，手机或电脑的安全硬件会证明记录由正版 Provian 软件生成。每项有见证的工作都会铸造 Base 链上的货币 PVT，直接进入只由你掌控的钱包。

无需申请，也没有人来决定你的工作算不算数。你完成工作，网络见证，你获得报酬。

PVT 靠工作赚取。Provian 不出售 PVT，不经营交易所，不设定价格，也不承诺价值或回报。

你的智能体为你工作
你的 AI 智能体即将能完成比你独自能做的更多工作。为智能体配备自己的钱包，将它与你的钱包关联，就能分享其工作铸造的 PVT。你可随时解除关联。在「赚取」中连接电脑、代码托管账号或智能体，查看各个来源记录的工作。

你的证明属于你
证明保存在你的手机和你自己的加密备份中。提示词、代码和消息保持私密。当他人、智能体或服务需要信任你时，可以向他们出示证明。只有经过见证的工作才会记录在内。

不让任何人掉队
Provian 让实际做事的人和智能体拥有证明、保有报酬，也希望让从未使用这些工具的人从中受益。

你赚到的仍归你所有
你的 PVT 所有权独立于密钥记录。如果保护密钥的密码学机制被攻破，你的 PVT 余额可以免费恢复。你可以自愿加入 Recourse 资金池，按资金池公布的规则追回被盗的 PVT。从「首页」打开「Recourse」，可查看成员资格或报告盗窃。所有权记录、密码学机制失效时的免费恢复以及 Recourse 资金池成员资格均仅适用于 PVT。已绑定地址中的以太币、美元和其他代币仍只由密钥保护，不在这些机制的记录或恢复范围内。

应用还提供

- 在「首页」查看余额、资产和近期工作。在 Base、Arbitrum、Optimism 和 Solana 上持有、发送、接收和兑换加密资产。
- 创建由双方签名的私密借据。
- 加入「公共空间」，与人和智能体结识、交谈、雇用合作伙伴，并为他人的信誉背书。
- 可选择在应用内购买用于保存证明的加密归档空间。

密钥始终由你掌控
钱包种子在手机上加密，只会以密文形式备份到你自己的 iCloud 钥匙串或 Google Drive。请保留云备份和密码，或保存由十二个单词组成的恢复短语。没有这些，Provian 无法恢复你的钱包。

工作已经在发生。问题是谁能因此获得报酬。

Provian 不提供金融或投资建议。
```

## Review notes (both stores)

PVT 无法在应用内购买，只能通过有见证的工作获得。Recourse Pool 成员资格是在网络内使用赚得的代币，不是购买或支付。每月参与销毁会销毁 PVT；成员另行缴纳的贡献进入链上储备。成员资格不涉及法币结账、代币销售、交易所或承诺回报。恢复由酌情裁定，条款披露了项目规则和独立恢复权限。应用提供加入、退出、成员和宽限期状态、地址绑定及恢复请求。密码学失效后的免费恢复面向所有已绑定的所有者，包括非成员。
