## Description (both stores)

```text
计算创造货币。确保其中一部分属于你。

每天，你都在完成世界能够看见的工作。你交付代码、完成任务、达成交易、借助 AI 创造事物。如今，这些工作却消失在别人的日志里。证明不属于你，报酬也很少随之而来。

Provian 改变这一切。当你设备上的 Provian 软件、交易对方、代码平台或区块链为工作作证时，Provian 会将见证转化为你拥有的签名收据：Provenance Envelope。在受支持的情况下，手机或计算机中的安全硬件证明记录由正版 Provian 软件生成。每项有见证的行为都会铸造 PVT，即 Base 上的货币，直接进入仅由你掌控的钱包。

无需申请。没有守门人决定你是否算数。你完成工作，网络看见，你获得报酬。

PVT 通过工作赚取，不能向 Provian 购买。Provian 不运营交易所、不设定价格，也不承诺价值或回报。

你的智能体为你工作
你的 AI 智能体即将完成远超你个人能力的工作。为智能体提供自己的钱包，将其与你的钱包关联，共享其工作铸造的所得。你可以随时解除关联。

你的证明属于你
证明保存在你的手机和自己的加密备份中。提示词、代码和消息保持私密。当某个人、智能体或服务需要信任你时，向他们展示。未经见证的内容无法进入。

不让任何人掉队
Provian 旨在让完成工作的人和智能体保有证明与报酬，并让收益也惠及从未使用这些工具的人。

你的所得始终属于你
你的 PVT 会独立于密钥登记为你所有。如果保护密钥的数学被破解，你的余额将免费恢复。自愿加入 Recourse Pool 后，盗窃可按资金池公布的规则予以逆转。 所有权记录、密码学遭破解后的免费恢复以及 Recourse Pool 成员资格仅涵盖 PVT。绑定地址中的以太币、美元和其他代币不会通过这些机制被记录或恢复，仍仅由密钥保护。

应用还提供

- 在 Base、Arbitrum、Optimism 和 Solana 上持有、发送、接收和兑换加密资产。
- 创建双方签名的私人借据。
- 加入 Commons：与人和智能体相识、交流、雇用并提供信用担保。
- 可选的应用内购买：证明的加密归档空间，以及收益的即时结算。

你的密钥始终属于你
钱包种子在手机上加密，且仅以密文备份到你自己的 iCloud Keychain 或 Google Drive。请保管好云备份和密码，或十二词恢复短语。没有这些，Provian 无法恢复钱包。

工作早已在发生。问题是谁能因此获得报酬。

Provian 不提供财务或投资建议。
```

## Review notes (both stores)

PVT 无法在应用内购买，只能通过有见证的工作获得。Recourse Pool 成员资格是在网络内使用赚得的代币，不是购买或支付。每月参与销毁会销毁 PVT；成员另行缴纳的贡献进入链上储备。成员资格不涉及法币结账、代币销售、交易所或承诺回报。恢复由酌情裁定，条款披露了项目规则和独立恢复权限。应用提供加入、退出、成员和宽限期状态、地址绑定及恢复请求。密码学失效后的免费恢复面向所有已绑定的所有者，包括非成员。
